an assistant I can vouch for.

v1 was a fleet of agents behind a gateway. it went down, quietly, and stayed down for weeks before anyone noticed. so v2 was built the other way round: the alarm first, then the assistant. I don't need to know how every part works. I need to know what it can't do without me, and how I'd catch it failing.

the controls came first

I'm an accountant. I don't trust a process because it worked yesterday; I trust it because of what's wrapped around it. these were running before the assistant could do a single useful thing.

  1. the alarm lives outside.

    a separate watchdog checks the assistant every few minutes. if it stops answering, my phone rings. the assistant can't reach its own alarm.

  2. a hard spending brake.

    one monthly cap, set where the bill is paid. when it's reached, everything stops. it doesn't quietly keep charging.

  3. one kill switch.

    a single stop that every risky action checks first. the assistant can't switch it back on.

  4. it asks before it reaches out.

    money, deleting things, passwords, or sending anything to another person: by design, none of it happens without a tap from me.

  5. two reviewers, strangers to each other.

    every change is reviewed twice, by reviewers that never see each other's notes or the author's reasoning. I don't review code. that's the point.

  6. one phase at a time.

    each phase has to run clean for a week before the next one is switched on. being built doesn't count.

so why is it still off? because "nobody found a way" isn't the bar. two things need a real answer first, and a patch won't do:

  • 513of about 5,400 tests can't run inside the sealed test run, so the gate is blind to whatever only they cover.
  • count ≠ listthe pass check compares how many tests passed, not exactly which ones. that can be fooled.

what I can say without reading the code

what it can't do without me

  • switch on its next phase.
  • change its own alarm, cap, or tests.
  • spend past the cap.
  • ship a change to itself.

how I'd catch it failing

  • it goes quiet: my phone rings, within about half an hour.
  • its files change underneath it: the watchdog's check goes red.
  • spend moves when I'm not using it: one command shows me.
  • I don't believe a claim: I ask for the receipt.
